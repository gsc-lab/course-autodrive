그림 1. 전원 배선

배터리 + 7.2 V접지서보 전원 6 V모터 전력선

위가 +, 아래가 접지입니다. 배터리 전류는 퓨즈를 지나 J2 에서 모터 드라이버와 UBEC 로 나뉘고 J3 에서 모입니다. Jetson 은 보조배터리로 따로 움직입니다.

그림 2. 신호 배선

논리 전원 3.3 V5 V (Jetson)신호접지서보 전원 6 V

Jetson 의 네 가닥이 서보용 보드를 거쳐 모터용 보드로 이어집니다. 속도는 J4, 방향은 J5 에서 MDD10A 의 두 채널로 나뉘어 두 모터가 항상 같은 신호를 받습니다. MDD10A 핀과 모터용 보드 GND 핀의 실제 위치는 그림 3 에 있습니다. 도트 매트릭스(X1~X5)는 Jetson 전원 영역 안에서만 이어지는 선택 부품입니다.

3. 접지

서보 커넥터 안의 검정선(S3)을 빼면 접지선은 일곱 가닥입니다. 전류가 돌아오는 선 넷과 신호의 기준이 되는 가는 선 셋입니다.

G1주행 배터리 −J3 1번14AWG배터리 −
G2J3 2번MDD10A B−14AWG모터 전류가 돌아오는 선
G3J3 3번UBEC 입력 −16AWGUBEC 입력 −

I4Jetson 핀 6 (GND)서보용 보드 6핀 헤더 GND22AWGJetson 의 유일한 접지선
C4서보용 보드 반대쪽 헤더 GND모터용 보드 6핀 헤더 GND22AWG보드 사이 연결

  • 차체로 가는 Jetson 의 접지선은 I4 하나뿐입니다. (X2 는 Jetson 과 도트 매트릭스 사이의 선이라 차체와 무관합니다.) 그래서 모터나 서보 전류가 Jetson 을 지나갈 길이 없습니다. Jetson 은 플라스틱 기둥으로 고정합니다. 금속 기둥은 접지선을 하나 더 만듭니다.
  • 모터 신호의 기준 접지는 D7 입니다. 신호선과 같은 다발로 다녀야 모터 전류의 영향이 신호에 실리지 않습니다.
  • 굵은 접지선 G2, G3, G4 는 확실히 조입니다. 하나가 빠져도 전류가 가는 접지선(D7, C4)으로 돌아 흘러 겉으로는 동작하지만, 가는 선이 뜨거워지고 퓨즈는 이를 막지 못합니다.

그림 3. 핀 위치

두 보드는 같은 제품이고 A0 납땜 여부만 다르므로 모터용 보드에 표시를 해 둡니다. 호환 보드는 인쇄가 다를 수 있으니 보드에 적힌 이름을 기준으로 꽂습니다.

그림 4. 모터용 보드의 주소 납땜

두 보드는 기본 주소가 같은 0x40 이라 한 버스에서 함께 쓸 수 없습니다. 모터용 보드의 A0 패드를 납으로 이어 0x41 로 바꿉니다.

이미 납땜된 보드를 받았다면 4절 1번의 scan 으로 확인만 하면 됩니다.

4. 조립 후 동작 시험

PCA9685 는 통신이 끊겨도 마지막 출력을 유지합니다. I2C 선이 빠지거나 프로그램이 멈추면 모터는 그 속도로 계속 돌고, 세울 방법은 배터리 커넥터를 뽑는 것뿐입니다. 커넥터는 손이 바로 닿는 곳에 두고, 시험은 바퀴를 띄우고 합니다.

배선을 2절의 표대로 모두 꽂은 뒤, 바퀴를 띄우고 주행 배터리를 연결하고 Jetson 을 켭니다. 아래 명령을 순서대로 실행해 서보와 모터가 동작하는지 봅니다.

순서명령정상정상이 아니면
1uv run python scripts/pin_test.py scan0x40 서보용 보드, 0x41 모터용 보드가 모두 "응답"둘 다 없으면 Jetson 케이블(I1~I4), 0x41 만 없으면 보드 사이 케이블(C1~C4)과 A0 납땜(그림 4)
2uv run python scripts/pin_test.py servo서보가 60° → 120° → 90° 로 움직인다안 움직이면 UBEC 출력(P5, G4)과 서보 커넥터(S1~S3) 방향. 5절 참조

5. 잘못 꽂기 쉬운 곳

실수결과막는 방법
I1 을 VCC 가 아니라 옆의 V+ 에 꽂음Jetson 의 3.3 V 에 6 V 가 들어가 파손된다VCC 와 V+ 는 이웃한 핀이다. 인쇄를 읽고 꽂는다
Jetson 쪽에서 핀 1 대신 핀 2, 핀 6 대신 핀 4 에 꽂음3.3 V 버스에 5 V 가 걸린다핀 2, 4 는 5 V 다. 바깥쪽 줄이 짝수 핀이다
두 PCA9685 보드가 뒤바뀜서보에 모터 신호가, 모터에 서보 신호가 간다모터용 보드에 표시를 한다. A0 를 납땜한 쪽이 모터용이다
속도 선과 방향 선이 뒤바뀜 (D1 과 D4, 또는 J4 와 J5 의 출력)한 방향으로만 돌고, 정지 명령에 전속으로 돈다채널 0 이 PWM, 채널 1 이 DIR 이다. J4 에서 나온 선은 PWM1, PWM2 에만, J5 에서 나온 선은 DIR1, DIR2 에만 꽂는다. MDD10A 인쇄(DIR1, PWM1 …)를 보고 맞춘다
J4, J5 에 가는 듀폰 점퍼선(26~28AWG)을 물림달리다 흔들려 빠지거나 접촉이 끊겨 모터가 멈추거나 멋대로 돈다22AWG 또는 더 굵은 선만 물리고, 레버를 닫은 뒤 당겨 본다
서보 커넥터를 뒤집어 꽂음서보가 움직이지 않는다검정이 보드 가장자리 쪽이다
MDD10A 의 B+ 와 B− 를 반대로 물림드라이버가 파손될 수 있다판매처 자료에 역극성 보호가 없다고 되어 있다. 배터리를 연결하기 전에 B+ 가 J2, B− 가 J3 에서 오는지 다시 본다
